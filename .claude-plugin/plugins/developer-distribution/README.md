# Developer Distribution

Free weekly trends on what developers read on daily.dev, with two skills that turn them into post ideas and post reviews.

```
/plugin install developer-distribution --marketplace dailydotdev/daily
```

What you get:

- **Developer trends**: the `getTrends` tool on the Developer Distribution MCP server (`https://api.daily.dev/mcp/startups`). It shows which topics developers read more and less last week, and which post formats and title patterns earned more reads, Bookmarks and comments. It's free and needs no account. Docs: https://docs.daily.dev/developer-distribution/
- **`developer-trends-ideas`**: turns your team's recent work into a post idea that fits what developers are reading.
- **`developer-trends-review`**: checks whether daily.dev feeds are likely to limit a post's reach and compares it with the trends. It suggests changes and never rewrites your post.

The trends are the same for everyone. Weekly trends on your own topics and publishing to a company page are part of daily.dev for Startups: https://daily.dev/startups
