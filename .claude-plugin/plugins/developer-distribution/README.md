# Developer Distribution

See what developers read this week, shape post ideas around it, and check a post before it goes out. Built on daily.dev reading data.

```
/plugin install developer-distribution --marketplace dailydotdev/daily
```

What you get:

- **Developer trends**: the `getTrends` tool on the daily.dev MCP server (`https://api.daily.dev/mcp/startups`). Which topics developers read more and less last week, and which post formats and title patterns earned more reads, Bookmarks and comments. Free, no account or sign-in needed.
- **`daily-dev-content-ideas`**: finds a post idea in your team's recent work and shapes its angle, format and title around what developers read.
- **`daily-dev-content-review`**: checks whether developers' feeds are likely to give a post limited reach, and reviews it against what developers read. Suggestions only; it never rewrites your post.

The trends are the same for everyone. Teams on daily.dev for Startups get weekly intel on their own topics and can publish to their company page from the same server once signed in: https://daily.dev/startups
