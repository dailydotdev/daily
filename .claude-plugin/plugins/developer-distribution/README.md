# Developer Distribution

See what developers read this week, shape post ideas around it, and check a post before it goes out. Built on daily.dev reading data.

```
/plugin install developer-distribution --marketplace dailydotdev/daily
```

What you get:

- **Developer trends**: the `getTrends` tool on the daily.dev MCP server (`https://api.daily.dev/mcp/startups`). Which topics developers read more and less last week, and which post formats and title patterns earned more reads, Bookmarks and comments. Free, no account or sign-in needed.
- **`developer-trends-ideas`**: finds a post idea in your team's recent work and shapes its topic, format and title around what developers read.
- **`developer-trends-review`**: checks whether developers' feeds are likely to give a post limited reach, and reviews it against what developers read. Suggestions only; it never rewrites your post.

The trends are the same for everyone. Weekly trends on your own topics and publishing to a company page are part of daily.dev for Startups: https://daily.dev/startups
